# Geometric Lib — документация

## Общее описание решения

Библиотека `geometric_lib` предоставляет набор функций для вычисления
площади и периметра базовых геометрических фигур:

- круг (`circle.py`)
- квадрат (`square.py`)
- прямоугольник (`rectangle.py`)
- треугольник (`triangle.py`)

Каждый модуль содержит две функции: `area(...)` и `perimeter(...)`.

### Математические формулы

**Площадь:**
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²
- Triangle: S = ah / 2

**Периметр:**
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
- Triangle: P = a + b + c

## Описание функций

### circle.py

- `area(r)` — принимает радиус `r`, возвращает площадь круга.
  Пример вызова: `area(5)` → `78.53981633974483`

- `perimeter(r)` — принимает радиус `r`, возвращает длину окружности.
  Пример вызова: `perimeter(5)` → `31.41592653589793`

### square.py

- `area(a)` — принимает сторону квадрата `a`, возвращает его площадь.
  Пример вызова: `area(4)` → `16`

- `perimeter(a)` — принимает сторону квадрата `a`, возвращает его периметр.
  Пример вызова: `perimeter(4)` → `16`

### rectangle.py

- `area(a, b)` — принимает стороны прямоугольника `a` и `b`, возвращает его площадь.
  Пример вызова: `area(3, 4)` → `12`

- `perimeter(a, b)` — принимает стороны прямоугольника `a` и `b`, возвращает его периметр.
  Пример вызова: `perimeter(3, 4)` → `14`

### triangle.py

- `area(a, h)` — принимает основание `a` и высоту `h`, возвращает площадь треугольника.
  Пример вызова: `area(4, 5)` → `10.0`

- `perimeter(a, b, c)` — принимает стороны треугольника `a`, `b`, `c`, возвращает его периметр.
  Пример вызова: `perimeter(3, 4, 5)` → `12`
