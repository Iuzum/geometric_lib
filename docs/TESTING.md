# План тестирования Geometric Lib

## 1. Цели и задачи тестирования

**Цели:**
- убедиться, что функции вычисления площади и периметра работают корректно;
- обнаружить ошибки в формулах и граничных случаях;
- обеспечить автоматическую проверку при каждом изменении кода.

**Задачи:**
- написать unit-тесты для всех функций модулей `circle.py`, `square.py`,
  `rectangle.py`, `triangle.py`;
- покрыть валидные и крайние значения;
- проверить, что ранее найденный баг в `rectangle.perimeter` больше
  не воспроизводится;
- задокументировать результаты запуска.

## 2. Описание тестируемого продукта

`geometric_lib` — библиотека на Python для вычисления площади и периметра
базовых геометрических фигур. Состоит из четырёх модулей:

- `circle.py` — `area(r)`, `perimeter(r)`
- `square.py` — `area(a)`, `perimeter(a)`
- `rectangle.py` — `area(a, b)`, `perimeter(a, b)`
- `triangle.py` — `area(a, h)`, `perimeter(a, b, c)`

**Требования к продукту:**
- корректные математические формулы площади и периметра;
- обработка нулевых значений;
- работа с целыми и дробными числами.

## 3. Область тестирования

**В области тестирования:**
- все функции `area` и `perimeter` во всех 4 модулях;
- валидные значения: положительные целые и дробные числа;
- крайние случаи: ноль, единица, равные стороны;
- регрессионный тест на исправленный баг в `rectangle.perimeter`.

**Вне области тестирования:**
- отрицательные значения — не входят в контракт функций, описанный
  в документации (`docs/README.md`);
- нечисловые значения (`str`, `None`) — код не выполняет явную
  валидацию типов;
- проверка неравенства треугольника (`a + b > c`);
- производительность и нагрузка;
- интеграция с внешними системами.

## 4. Методы тестирования

- **Unit-тесты** на базе стандартной библиотеки Python `unittest`.
- **Автоматический запуск** одной командой:
  `python3 -m unittest discover -v`
- **Операторы сравнения**: `assertEqual` (для целых) и
  `assertAlmostEqual` (для дробных с плавающей точкой).
- **Именование тестов**: каждый тестовый метод начинается с `test_`,
  классы наследуются от `unittest.TestCase`.
